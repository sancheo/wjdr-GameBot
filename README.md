# 无尽冬日GameBot

目前实现《无尽冬日》安卓模拟器上的**联盟互助、探险经验领取、士兵训练、联盟科技捐献、免费英雄招募、仓库补给、生命之树、晨曦回礼和宠物技能**，
并支持**强制下线后重连**。运行端是 Mac，通过 ADB 连接本机 Android 模拟器。

## 运行

需要 macOS、Python 3、Pillow、PyObjC 的 Vision 桥接，以及项目内 `.tools/platform-tools/adb`。ADB 取自
[Android 官方 Platform Tools](https://developer.android.com/tools/releases/platform-tools)。
Pixel 5 模拟器须保持 1080×2340 分辨率及游戏前台；模拟器启动和重连时会尝试从活动弹窗、聊天页、海岛或野外页返回主城。

### 图形界面

安装下方依赖后，在 macOS 上运行：

```sh
python3 gui.py
```

界面会检测已连接的模拟器，供下拉选择，也可点击“刷新”重新扫描。初次启动窗口为 1040×800 像素，任务卡片按三列显示，无需滚动即可看到完整界面。窗口可从边角调整宽高，文字、图标和控件保持大小，拖动过程中任务卡片随宽度实时切换三列（1040 像素起）、两列（740 像素起）或一列；最小窗口为 560×560，内容超出时可滚动查看。窄窗口将启动区域换到下一行，避免遮挡刷新按钮。任务按日常、练兵与联盟、结晶与连接分类排列，使用独立开关；练兵下的盾兵、矛兵、射手可以分别关闭。生命结晶达到填写的阈值才会收集，阈值必须大于 0，默认 1000。强制下线重连可独立关闭，开启时可填写大于 0 的等待分钟数。抽屉任务仍需使用已校准的 1080×2340 模拟器。

界面图标位于 `assets/ui/`，由原始 1536×1024 设计稿裁出；可运行 `python3 scripts/build_gui_assets.py 设计稿.png` 重建。主 Logo 使用指定的 App Store 原图，Dock 图标另加透明留白。macOS 安装了 PyObjC 时使用原生图像视图保持 Retina 清晰度；其余环境使用平滑缩放的图片。空日志页与日志文本框独立显示，日志出现后可正常选择、复制。

调度与截图回归：`python3 -m unittest test_help_bot test_schedule -v`。macOS 上请将视觉识别测试与桌面交互测试分进程运行，避免 Vision/Tk 初始化冲突。

桌面交互检查：`GAMEBOT_GUI_TEST=1 python3 -m unittest test_gui -v`（需在图形桌面会话运行）。

点击蓝色“启动”后先检查联盟互助，再检查全部已开启任务；断线重连后也先检查互助，再重新检查任务。随后按各任务倒计时持续运行，并在间隔期间检查联盟互助和强制下线。运行中按钮变为红色“停止”；点击后结束脚本。普通运行异常会记录原因，每隔 10 秒恢复页面并重试，最多重试 3 次。定时任务仍失败时，本次运行后续的定时检查会跳过该任务，日志以红色 ⚠️ 提示，其他任务继续运行。若连续三个任务均耗尽三次重试，则立即退出脚本，并打印红色日志“⚠️ 当前已出现三个任务连续执行异常因此自动中断脚本”；任一任务检查成功即清零连续失败计数。非定时操作重试失败仍会退出并弹窗提示。强制下线仍按重连设置处理。完整过程保留在窗口日志里，每条日志带有精确到秒的时间，长文本自动换行，日志框高度不随内容变化，更多内容在框内滚动；最小窗口也可通过外层滚动条看到完整日志区域。关闭自动重连后若检测到强制下线，脚本会停止并提示原因。配置在运行期间锁定，停止后可重新调整。

```sh
python3 -m pip install 'Pillow>=10,<12' pyobjc-core pyobjc-framework-Cocoa
python3 help_bot.py --self-test
python3 help_bot.py --duration 60 --dry-run
python3 help_bot.py --duration 600 --max-clicks 20
```

本机 Pixel 5 模拟器运行联盟互助：

```sh
python3 help_bot.py --device emulator-5554 --duration 60 --dry-run
python3 help_bot.py --device emulator-5554 --duration 600 --max-clicks 20
```

先运行只观察模式，确认识别到互助，再运行允许点击的命令。模拟器配置已在
1080×2340 的国服主城验证。长期运行所有日常任务：

```sh
cd /Users/sanche/work/GameBot
python3 help_bot.py --device emulator-5554 --daily-tasks --forever --reconnect-minutes 1
```

`--daily-tasks` 启动时先检查探险经验，再按顺序检查：盾兵、矛兵、射手训练 → 联盟捐献 → 免费招募 → 仓库补给 → 体力罐头 → 生命结晶收集 → 晨曦回礼，关闭的功能直接跳过。同一轮检测复用已打开的抽屉：无需执行时继续检查后续任务，必要时在抽屉内滚动定位，全部抽屉任务检查结束后收起，再检查宠物技能。
练兵检测到“建筑升级中”时跳过该兵种，不记录其倒计时，也不点击领取或训练；其余兵种正常执行。全部已选兵种都在升级时每 10 分钟复查建筑状态。训练按已开启兵种中最早完成的时间再次检查；高级招募、史诗招募、仓库补给和晨曦回礼各自读取画面倒计时（仓库领取后读取建筑上的计时），记录预计完成时间，到时再次检查。倒计时识别不清时记录原因并在 60 秒后重新检测，不臆造冷却时长。启动及强制下线恢复后清空旧的等待时间，先检查互助，再立即重新检测全部已开启任务。每 10 分钟的抽屉巡检仅检查联盟捐献和生命结晶；探险红点保持独立的每 10 分钟检查。
“宠物技能”开关控制心灵伴侣、重物搬运、敏锐感官、大地馈赠四个技能。抽屉任务结束后通过右下角爪印进入弹窗，逐个核对技能名称并使用可用技能；冷却中的技能各自记录剩余时间，到期再检查。使用后确认进入冷却再记录下一次时间；读数不清时 60 秒后复查。关闭开关或传入 `--no-pet` 可禁用。
生命之树只在抽屉显示的“可收集”数**达到设定阈值**时领取，默认阈值为 1000。进入海岛后识别标题文字，逐个点击所有可见的结晶领取图标（包括被引导手指遮挡的图标），确认消失后继续查找。退出海岛时最多等待 8 帧，连续两帧确认主城后继续；超时会保存最后一帧和底栏差异供排查。程序启动后每 24 小时清理一次此类故障截图，新增截图时也立即清理：最多保留最近 20 张且不超过 30 天；其他测试和手工样本不自动删除。仓库补给有绿色可领取提示时进入仓库领取，随后立即独立检查体力罐头；两者共用“仓库补给”开关。罐头检查会先收起抽屉，仓库不在画面时通过盾兵营定位后滑动主城到仓库，确认建筑和罐头图标再领取，并等待图标动画。领取后记录时间及仓库上白色倒计时对应的下一次检查时间，到时自动重新定位并检查罐头，不依赖仓库补给再次可领取。绿色“剩余时间”是本次罐头的领取窗口，不作为下一次领取时间；白色计时不清时 60 秒后重试。滑动路径按当前主城建筑布局校准，仓库定位失败时停止点击并走任务重试。
晨曦回礼有绿色可领取提示时点开领取，并在奖励页返回主城。
抽屉任务执行期间也会检查并响应右下角联盟互助；其余时间持续按 `--interval`（默认 2 秒）检查。
互助点击误入聊天页时，识别“聊天”标题并点左上角返回主城，再继续脚本。
`--forever` 不限制运行时长和互助次数；按 Ctrl-C 停止。Mac、模拟器和游戏都需要保持运行。
本功能不领取主城资源产出。

只需捐献和免费招募时使用 `--city-tasks`，只需士兵训练时使用 `--train`：

```sh
python3 help_bot.py --device emulator-5554 --city-tasks --duration 600 --max-clicks 20
python3 help_bot.py --device emulator-5554 --train --duration 600
```

抽屉任务向下巡检到“可捐献”时
进入联盟科技，选择屏幕上带绿色点赞的科技，持续长按右侧的普通资源捐献按钮，直到按钮变灰
无法继续捐献，随后返回主城。程序不会按左侧消耗钻石的按钮。
之后分别检查高级招募和史诗招募，两者有独立倒计时与到期任务，共用界面的“免费招募”开关。有免费提示时会等待招募页面与按钮显示，只点击对应类型已确认免费的单次按钮，从奖励页返回主城。若页面显示“下次免费”，则跳过并更新倒计时；连续识别失败时保存两次失败画面供排查。
每次跨页面点击前都会确认目标界面；找不到相应提示就跳过。模拟器上的强制下线弹窗已用
1080×2340 的实际截图校准。任务执行发生异常时也会重新截图确认弹窗，确认后等待重连，再重试任务。

只观察模式找到互助或强制下线弹窗后会立即退出。普通互助模式默认持续 120 秒、每轮间隔
2 秒、最多点击 10 次；可用 `--duration`、`--interval`、`--max-clicks`
调整。启用抽屉任务后，各任务按上述倒计时或巡检间隔执行，互助次数不设上限。
如果电脑连有多台设备，使用 `--device`
指定 ADB 序列号。

程序仅在底栏匹配到主城、屏幕尺寸正确，且目标游戏位于前台时点击。
互助点击后会等待多帧确认图标消失或角标变化；仍在主城但图标未更新时，等待 30 秒再检测，不会立即重复点击或误报停止。无法确认主城时仍会报告实际异常。
检测到“账号已经在其他设备登录，您已被强制下线”弹窗后，暂停互助操作，
用单调时钟等待满 `--reconnect-minutes` 指定的时间（默认 10 分钟，可设为 1 分钟）。等待结束时再次确认弹窗和游戏前台，才点击
“重新连接”；弹窗已消失时取消点击。等待时间不计入 `--duration`。
启动和重连后会识别并关闭右上区域的活动弹窗和“欢迎回来”弹窗，聊天页点击左上角返回，野外页点击右下角“城镇”；连续三次确认回到主城后才继续日常任务，一分钟仍无法确认时停止。模拟器的野外和活动按钮已用实际截图校准。
如果重连后再次出现同一弹窗，会重新等待设定的时间。电脑在这段时间须保持运行，
模拟器须保持 ADB 连接和游戏前台。

全部任务使用已校准的 Pixel 5 模拟器配置，默认加载模拟器模板。
生命之树数量由 macOS Vision 识别，未识别出数字时跳过。单张截图来源的
模板和阈值还需要更多游戏状态验证；无法确认页面或领取结果时程序会停止，避免误点。

`assets/` 中是用于识别的局部图标；`artifacts/` 中的完整设备截图
可能包含角色和聊天信息，提交前请检查。
