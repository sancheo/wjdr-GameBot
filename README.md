# 无尽冬日GameBot

目前实现《无尽冬日》安卓设备上的**联盟互助、探险经验领取、士兵训练、联盟科技捐献、免费英雄招募、宠物寻宝、仓库补给、生命之树、晨曦回礼、宠物技能、灯塔情报、自动打怪、自动打熊和资源采集**，并支持**强制下线后重连**。



## 安装与使用

压缩包中包含 **Python、程序依赖、OCR 模型、ADB、Visual C++ 运行库和 WebView2 运行环境**。

### 第 1 步：准备夜神模拟器

1. 安装并打开夜神模拟器，新建Android 7 32bit 的模拟器后启动模拟器。
2. 在夜神模拟器中使用浏览器访问官网wjdr.cn，安装《无尽冬日》国服并登录，等待游戏资源下载完成后保持游戏在前台。
3. 关闭电脑的自动休眠，运行期间保持电脑、模拟器和游戏开启。

### 也可使用 USB 连接安卓手机

1. 在手机上开启“开发者选项”，启用 **USB 调试**。
2. 使用支持数据传输的 USB 数据线连接电脑，解锁手机，在“允许 USB 调试”弹窗中确认授权。
3. 打开 GameBot，点击“刷新”，在“安卓设备”列表中选择标有“真机”、状态为“已连接”的手机。手机按 ADB 序列号独立保存任务配置。
4. 手机需安装《无尽冬日》国服并登录，保持游戏前台、屏幕解锁和数据线连接。

### 第 2 步：解压并打开 GameBot

1. 将整个便携版压缩包解压到当前用户可写的本地目录，例如 `D:\GameBot`。不要在压缩包预览窗口中直接运行，也不要使用网络共享目录。
2. 双击目录中的 **GameBot.exe**，等待 GUI 打开。
3. 点击“刷新”，在“安卓设备”列表中选择已就绪的夜神模拟器或已通过USB连接的真机。

### 第 3 步：通过 GUI 验证并运行任务

1. 使用时，在 GUI 中逐项浏览并开启需要的功能，点击“启动”。
2. 查看模拟器中的实际操作，以及 GUI 的“任务执行状态”和“运行日志”，确认主城识别、点击位置和任务执行正常。
3. 出现问题时，查看 GUI 的“异常信息”或异常退出提示，按其中显示的路径打开异常截图，结合当时的游戏画面排查。



同时启动多台模拟器时，请在 GUI 中选择本次要运行的设备。修改任务配置前先停止任务。

## 常见问题



### 程序异常时如何排查？

1. 查看 GUI 的“任务执行状态”，确认出问题的任务及停用原因；再查看“运行日志”中的红色“异常信息”或异常退出提示。
2. 根据异常信息显示的完整路径，在文件资源管理器中打开异常截图，检查是否停留在弹窗、登录页面、错误页面或其他非预期界面。
3. 手动处理异常界面并返回主城。程序仍在运行且任务已停用时，可在“任务执行状态”中点击该任务的“单项重试”；任务运行已停止时，处理问题后重新点击“启动”。
4. 如需反馈问题，请提供任务名称、发生时间、GUI 异常信息和对应异常截图。

任务首次异常后，程序每隔 10 秒尝试恢复主城并重试，最多连续重试 3 次。第 3 次重试仍失败时，会在恢复界面前保存当前模拟器的彩色截图，并在 GUI 中报告原因和截图路径，随后停用该任务。前面的失败会记录日志，但不一定生成截图。已停用的任务在强制下线重连后仍保持停用，可通过“单项重试”重新验证；重新启动任务运行也会恢复执行。

运行日志和异常日志保存在 `logs/<设备>/<YYYY-MM-DD>/` 下，保留 7 天。GUI 仅显示本次打开后的日志，启动或选择设备时不恢复上次运行记录；点击停止不会清空或截断本次日志，切换设备不会混合大小号记录。

异常截图保存在解压目录的 `artifacts/exception_screenshots/<模拟器>/<YYYY-MM-DD>/` 下，按模拟器和日期分类，保留 7 天并自动清理。请及时保存需要反馈的截图。若模拟器断开、ADB 不可用或截图保存失败，GUI 会显示相应原因；此时请提供异常信息。

### GUI 中没有模拟器或模拟器未就绪

先打开夜神模拟器，等待安卓桌面完全出现，再回到 GameBot 点击“刷新”。仍无法识别时，先停止任务，在夜神自身界面关闭并重新启动模拟器，然后刷新列表。

USB 真机请确认已开启 USB 调试、允许当前电脑调试，并使用支持数据传输的数据线。列表显示“待授权”时，在手机上确认弹窗后刷新；完全未出现时，检查 Windows 的 ADB USB 驱动，参见上方“使用 USB 连接安卓手机”。

### 找不到 ADB 或提示无法启动 ADB

便携包已带有 ADB。先确认完整解压了压缩包，且 `.tools/platform-tools/` 中的文件没有被删除或隔离；文件缺失时重新解压。

修复后，重新打开夜神与 GameBot，在 GUI 中刷新并验证连接。

### 不同屏幕尺寸的运行方式

程序会把不同尺寸的竖屏截图自动映射到 **1080×2340** 的逻辑画布，复用现有识别素材，并把点击、滑动转换回手机实际坐标。已使用 **1176×2400** 真机截图进行适配回归；不同长宽比通过顶部、中心和底部锚点处理，而非直接拉伸整张画面。游戏界面大幅变化、横屏或分屏布局不属于已验证范围。异常截图保留手机原始分辨率，便于排查。缩放模拟器在电脑上的窗口不会改变截图分辨率。

### 提示游戏不在前台或无法确认主城

进入模拟器，确认显示的是《无尽冬日》国服中文界面的主城，关闭活动弹窗，退出登录页或其他应用。处理后回到 GUI 重新启动任务，或对已停用的任务点击“单项重试”。若仍失败，请结合 GUI 异常信息和异常截图排查。

非国服、非中文界面或游戏界面大幅改版时，现有识别素材可能不适用。

匹配素材统一从夜神模拟器实际游戏截图采集和更新，优先使用小号验证。采集时保留原始画面及逻辑画布截图，裁剪来源登记在 `assets/nox-samples.json`；未登记的历史素材继续等待实际页面采集后替换。历史真机及其他设备截图仅用于兼容性回归。

### OCR 加载失败或 GUI 无法打开

确认使用的是 **Windows 10/11 64 位**，并已完整解压便携包。不要单独移动 `GameBot.exe` 或删除 `runtime/`、`assets/` 中的文件。

关闭程序后，将便携包重新解压到当前用户可写的本地目录，再双击 `GameBot.exe` 验证。若仍失败，请提供启动提示；能进入 GUI 时，同时提供其中的异常信息和异常截图（如已保存）。

### 如何更新或保留配置？

程序启动后会在后台检查 [GitHub Releases](https://github.com/sancheo/wjdr-GameBot/releases) 的最新正式版本，也可以点击主标题下的当前版本号手动检查。窗口可见时每天自动检查一次，也可随时手动检查。检查时版本号显示加载动画；已是最新版本的提示显示三秒后恢复版本号。检查失败会持续显示红色错误提示，可点击重试，不影响自动任务。此功能无需安装 Git 或其他软件，只需要能访问 GitHub。

发现新版本后，当前版本号位置显示红色“有新版本：v版本号”，完整便携版会自动在后台下载并校验，下载期间现有任务继续运行。点击版本号可查看更新说明及实时下载进度。点击“更新”才会安装：已下载完成时直接安装；尚未下载完毕时继续显示同步进度，下载校验完成后自动安装，无需再次点击。点击“取消”或关闭弹窗会撤销本次安装请求，后台下载继续，之后仍可重新打开并点击“更新”。下载失败时显示错误，可重试更新。

新版会比较本地文件与发行清单的 SHA-256，只下载新增或修改文件的压缩数据，未变的 Python、WebView2 等运行环境不重复下载。旧发行版未提供文件清单或服务器不支持分段下载时，自动使用完整包；清单或文件校验失败会停止更新。安装时程序停止当前自动任务并退出，由包内的 `GameBot.Updater.exe` 替换程序和运行环境，完成启动检查后重新打开 GUI。`configs/` 配置、`logs/` 日志和 `artifacts/` 截图会保留。更新后任务保持停止，请检查配置后手动启动。文件差异更新只替换变化的程序文件，并删除上一版清单中已移除的文件；额外放入的未知文件不自动删除。安装或新版启动检查失败时，会尝试恢复旧版，并显示错误；若恢复失败，提示会给出备份目录。

安装更新前，请关闭同一解压目录中其他 GameBot 窗口，等待模拟器启动或重启完成，差异更新需留出变更文件及回滚备份的空间；完整包更新需留出至少压缩包大小四倍加 512 MiB 的空间。建议解压到较短目录，例如 `F:\GameBot`，避免旧版更新程序的路径长度限制。不要删除 `GameBot.Updater.exe`。自动更新面向公开仓库的完整 Windows 便携发行包，草稿、预发布版本和源码 ZIP 不用于自动安装。

旧包没有更新功能或网络无法下载时，可停止任务并关闭旧程序，将新版便携包完整解压到新目录，再复制旧目录的 `configs/`。需要保留旧日志、异常截图时，同时复制 `logs/` 和 `artifacts/`，随后打开新版 GUI 检查设置。

### 发布文件更新清单（维护者）

`scripts/build_portable.py` 构建便携包时同时生成 `.zip.sha256`、`.files.json` 和 `.files.json.sha256`。发布 Release 时需一起上传这四个附件。文件清单记录每个文件的大小、SHA-256 和压缩数据位置；客户端通过 GitHub 的分段下载取得变更文件，无需按旧版本分别打补丁。完整 ZIP 继续用于首次安装、旧客户端和兜底。
